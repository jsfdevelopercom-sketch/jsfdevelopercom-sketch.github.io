Method of Apache Calculation
This app uses a standard APACHE II point binning approach. Oxygenation uses PaO₂ when FiO₂ < 50% and A–a gradient when FiO₂ ≥ 50%. For acid–base: pH is preferred if present, else HCO₃⁻ is used.
Parameter Ranges → Points
Temperature (°C) ≥41 → 4 • 39–40.9 → 3 • 38.5–38.9 → 1 • 36–38.4 → 0 • 34–35.9 → 1 • 32–33.9 → 2 • 30–31.9 → 3 • <30 → 4
MAP (mmHg) ≥160 → 4 • 130–159 → 3 • 110–129 → 2 • 70–109 → 0 • 50–69 → 2 • <50 → 4
Heart Rate (bpm) ≥180 → 4 • 140–179 → 3 • 110–139 → 2 • 70–109 → 0 • 55–69 → 2 • 40–54 → 3 • <40 → 4
Respiratory Rate (/min) ≥50 → 4 • 35–49 → 3 • 25–34 → 1 • 12–24 → 0 • 10–11 → 1 • 6–9 → 2 • <6 → 4
Oxygenation If FiO₂ ≥ 50%: A–a ≥500 → 4 • 350–499 → 3 • 200–349 → 2 • <200 → 0
If FiO₂ < 50%: PaO₂ >70 → 0 • 61–70 → 1 • 55–60 → 3 • <55 → 4
pH ≥7.70 → 4 • 7.60–7.69 → 3 • 7.50–7.59 → 1 • 7.33–7.49 → 0 • 7.25–7.32 → 2 • 7.15–7.24 → 3 • <7.15 → 4
HCO₃⁻ (mEq/L) (used only if pH missing) ≥52 → 4 • 41–51.9 → 3 • 32–40.9 → 1 • 22–31.9 → 0 • 18–21.9 → 2 • 15–17.9 → 3 • <15 → 4
Na⁺ (mEq/L) ≥180 → 4 • 160–179 → 3 • 155–159 → 2 • 150–154 → 1 • 130–149 → 0 • 120–129 → 2 • 111–119 → 3 • <111 → 4
K⁺ (mEq/L) ≥7.0 → 4 • 6.0–6.9 → 3 • 5.5–5.9 → 1 • 3.5–5.4 → 0 • 3.0–3.4 → 1 • 2.5–2.9 → 2 • <2.5 → 4
Creatinine (mg/dL) ≥3.5 → 4 • 2.0–3.4 → 3 • 1.5–1.9 → 2 • 0.6–1.4 → 0 • <0.6 → 2
Acute renal failure = Yes → points are doubled
Hematocrit (%) ≥60 → 4 • 50–59.9 → 2 • 46–49.9 → 1 • 30–45.9 → 0 • 20–29.9 → 2 • <20 → 4
WBC (×10³/mm³) ≥40 → 4 • 20–39.9 → 2 • 15–19.9 → 1 • 3–14.9 → 0 • 1–2.9 → 2 • <1 → 4
GCSPoints = 15 − GCS
Age points ≤44 → 0 • 45–54 → 2 • 55–64 → 3 • 65–74 → 5 • ≥75 → 6
Chronic health points If chronic = No → 0
If chronic = Yes and surgery = Elective → 2
If chronic = Yes and surgery = Emergency / Non-operative → 5
Mortality bands (display) 0–4 → 4% / 1% • 5–9 → 8% / 3% • 10–14 → 15% / 7% • 15–19 → 25% / 12% • 20–24 → 40% / 30% • 25–29 → 55% / 35% • 30–34 → 73% / 73% • ≥35 → 85% / 88%
How to Fill the Form
  • Open Form tab.
  • Fill Patient details (Name, UHID, Age, Sex, Admission Date, Diagnosis, GCS).
  • Enter Clinical inputs (Vitals, Oxygenation, Labs).
  • Choose Mortality Y/N.
  • Scroll down and click Submit to Google Sheets.
Important: On clicking submit, the data is just sent to the server — it does NOT guarantee an Excel entry yet.
  • If the server actually inserts the row into the monthly sheet, you will see: Successfully submitted to Google Sheets ✅
  • If something fails (network, secret, script error), you will see an error message.
Controls
  • Open Controls tab to view the month’s entries.
  • Use the Month selector to switch months.
  • Refresh is manual — if you want the Excel to refresh here, you must click Refresh.
Mortality Update (KP) steps:
➤ Enter UHID
➤ Select Y or N
➤ Click Add (it goes to the queue)
➤ Repeat for multiple UHIDs
➤ Click Update and WAIT
  • If you switch tabs and come back, the entries table will show cached data (fast).
  • Only Refresh forces reloading from the server.
